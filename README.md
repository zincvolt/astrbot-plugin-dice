# astrbot-plugin-dice

桌游骰娘：**按标准骰式掷骰，只输出一行结果**。适用于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 4.28+。

零配置、无状态、不联网、不调模型。复制目录到 `data/plugins/` 重启 AstrBot 即可。

## 用法

所有指令都走 AstrBot 的唤醒前缀 `/`（本项目就是 `/`）：

| 指令 | 例子 | 说明 |
|---|---|---|
| `/r <骰式>` | `/r 1d20` | 基本掷骰 |
| `/roll <骰式>` | `/roll 2d6+3` | 同上 |
| `/dice <骰式>` | `/dice d%` | 百分骰（1~100） |
| `/骰 <骰式>` | `/骰 4d6kh3` | 中文别名 |
| `/掷骰 <骰式>` | `/掷骰 2d20kl1` | 中文别名 |
| `/投骰 <骰式>` | `/投骰 1d6!` | 中文别名 |

只写指令不给骰式（`/r`）会回用法提示。输出形如：

```
/r 2d6+3     → 🎲 2d6+3 = 4+5+3 = 12
/r 4d6kh3    → 🎲 4d6kh3 = 6+5+4+2(弃) = 15
/r d%        → 🎲 d% = 73 = 73
/r 1d6!      → 🎲 1d6! = (6+3) = 9
```

## 骰式语法

```
[颗数]d面数 [kh N | kl N] [!]  [+/- 常数] ...
```

- `NdM`：掷 N 颗 M 面骰；`dM` 时 N 默认为 1
- `d%`：等于 `d100`
- `khN` / `klN`：取最高 / 最低 N 颗（比如 `4d6kh3`、`2d20kl1` 劣势骰）
- `!`：爆骰，掷出最大面再掷一次，最多重掷 20 次（`1d6!`）
- `+3`、`-1`：常数修正，可以写在骰式前或后，也可以有多项
- 大小写不敏感，空格随意：`/r 2D6 + 3` 也能识别

上限：一次最多 100 颗、每颗最多 1000 面、修正值最多 1000000、
总掷骰次数（含爆骰）最多 200、骰式最长 64 字符。超出会明确报错，不静默截断。

## 为什么不会抢指令

这是本插件最在意的一点。本项目曾出现过别的插件用「带地名就当展会查询」
的兜底把 `/` 指令吞掉，所以这里刻意做成：

1. **只注册精确指令**：`@filter.command("r", alias={...})`，只有 `/r `、
   `/roll ` 等完整命中才进 handler。
2. **没有全局消息处理器**：不注册 `event_message_type(ALL)`、不注册正则
   兜底，不会去「猜」用户是不是在掷骰。
3. **不碰没命中的消息**：其他插件的 `/help`、`/下次展`、`/判官` 等一律
   不进入本插件。
4. **命中后立刻 `stop_event()`**：掷完/报错都把事件停掉，不会再由大模型
   补一句话，也不会被复读机复读。
5. **优先级 `maxsize`**：与兽聚的展会卡同档，高于复读机、判官和群聊上下文。
   命中后 `stop_event()`，框架在调用后续 handler 前会检查它并直接中断；
   没命中时本 handler 根本不会被激活，不会干扰任何别的指令。

别名只选了 `r / roll / dice / 骰 / 掷骰 / 投骰`，与本项目已装插件和框架
自带指令均无重叠。`@` 机器人再发 `/r 1d20` 也能用。

## 实现说明

- 不用 `eval` / `exec`，表达式走有限状态解析，非法输入只回提示
- 随机数来自 `random.SystemRandom()`（系统熵源），不是可预测的伪随机序列
- 爆骰和 kh/kl 组合时，**每颗骰子的爆骰总和**才参与大小比较
- 没有配置文件、没有开关、没有任何跨消息状态；删掉目录即可卸载

## 安装

```bash
cd <AstrBot>/data/plugins
git clone <this-repo> astrbot_plugin_dice
# 重启 AstrBot（本项目用 scripts/restart-astrbot.ps1，不用重启 QQ）
```

## 自测

仓库里有两个自测脚本：

```bash
python test_dice.py                 # 纯标准库，2832 项：解析、边界、分布、爆骰
python test_handler.py              # 需 AstrBot 环境：6 个精确指令 + 不吞其他指令
```

`test_handler.py` 默认从 `D:\QQNTBOT\apps\AstrBot` 读 AstrBot 源码，其他机器用
`ASTRBOT_ROOT` 环境变量指到自己的 AstrBot 目录。
